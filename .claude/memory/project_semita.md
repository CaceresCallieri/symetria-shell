**Semitas** — a browser extension that opens a glassmorphic card overlay via keybind, showing ~10 curated links for instant navigation to frequently visited places.

**Why this name:** Semitas (Latin plural of semita: narrow paths, footpaths, byways) captures the concept of personal, well-worn routes — as opposed to "viae" (the public roads). The user's frequent destinations are their semitas through the web. Plural form chosen deliberately: the extension is about the collection of paths, not a single concept.

**How to apply:**
- Target browser: Zen Browser (primary), but designed to be browser-agnostic (Firefox/Chromium compatible)
- UX: keybind → glassmorphic floating cards → click to navigate
- Design: glassmorphism aesthetic, ~10 configurable link cards
- This is a standalone project in the constellation, NOT a Symmetria sub-component (browser extensions are cross-platform)
- Runners-up considered: Limen (threshold), Tropos (direction/turn), Iter (journey/route) — user chose Semita for its personal, well-worn quality
