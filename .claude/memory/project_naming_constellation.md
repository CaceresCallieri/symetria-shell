The user's projects form a philosophical constellation where each name is a conceptual container:

## Conceptual / Personal Systems

| Name | Greek/Latin Root | Concept | System | Status |
|------|-----------------|---------|--------|--------|
| **Kosmos** (κόσμος) | Greek: order, world | Order emerging from chaos | Task management app | Active |
| **Symmetria** (συμμετρία) | Greek: due proportion | Harmony through proportion | Desktop environment (umbrella) | Active, expanding |
| **Vigilia** | Latin: watchfulness | Readiness and presence | Remote dev server provisioning | Mature |
| **Semitas** | Latin: narrow paths, footpaths | Mastery of familiar routes | Browser extension (quick navigation) | Named, pre-development |

| Symmetria Agents | Agents | Agent bar / AI workflow dashboard |

## Naming Pattern

- Conceptual projects: Greek or Latin roots, abstract meaning, timeless tone
- Commercial projects: Professional, bilingual (ES/EN), credible to target industry
- Symmetria sub-components: "Symmetria [Domain noun]" — name the domain, not the tool type

**Why:** Tracking the full constellation helps maintain coherence when naming future projects. Each name should feel like it belongs in this family without copying the pattern of its siblings.

**How to apply:** When naming new projects, consult this map to ensure the new name occupies its own conceptual space and doesn't overlap with existing entries.
